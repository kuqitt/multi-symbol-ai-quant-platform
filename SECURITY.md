# Security Policy / 安全策略

## English

### Supported Use

This repository is developed in the open. The latest `main` branch is the primary supported line for fixes.

### Reporting a Vulnerability

Please do not open a public issue for any vulnerability involving:

- credential exposure
- authentication bypass
- approval bypass
- remote code execution
- exchange order abuse
- fund safety risk

Instead, report privately to the maintainers once a dedicated security contact is published.

Until then, minimize disclosure and avoid posting proof-of-concept details publicly.

### What To Include

- affected component
- impact
- reproduction steps
- logs or screenshots if available
- suggested mitigation if known

## 简体中文

### 支持范围

本仓库以开源方式持续开发，默认以最新的 `main` 分支作为主要修复线。

### 如何报告漏洞

对于以下类型的问题，请不要直接公开提 issue：

- 凭据泄露
- 鉴权绕过
- 审批绕过
- 远程代码执行
- 交易接口滥用
- 真实资金安全风险

在项目明确安全联系方式之前，请尽量减少公开披露范围，不要直接发布可利用细节或完整 PoC。

### 建议提供的信息

- 受影响组件
- 影响范围
- 复现步骤
- 日志或截图
- 如果已知，可附上临时缓解方案
